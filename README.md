# Veridify

Nigerian businesses are making high-stakes financial decisions based on images they cannot verify.

An insurance adjuster receives a claim photo over WhatsApp. A marketplace moderator reviews a product listing. A journalist fact-checks a news image. In each case, they are looking at something that could be real, tampered, or entirely fabricated — and they have no way to know which.

Generative AI tools have made this worse. Midjourney, Stable Diffusion, DALL-E, and FLUX are now accessible to everyday people, which means they are accessible to everyday fraudsters. A convincing fake no longer requires expertise. It requires a prompt.

Insurance fraud in Nigeria costs an estimated ₦100 billion annually. AI-generated images are a growing vector. There is no affordable, locally-priced verification tool built for this market.

**Veridify is that tool.**

Submit any image. In under 3 seconds, Veridify tells you whether it is authentic, whether it has been manipulated, or whether it was generated by an AI — with a trust score, a confidence level, and a breakdown of what the model found. Every verification is billed at ₦175, deducted from a pre-funded balance via Squad's payment rails. No contracts. No minimum commitments. Pay as you verify.

---

## What Veridify detects

**AUTHENTIC** — A real photograph. Natural camera sensor noise. No signs of digital alteration or AI generation.

**MANIPULATED** — A real photograph that has been tampered with after the fact. Something was added, removed, cloned, spliced, or altered. The base image is real but regions within it are not. This is the fraud pattern most common in insurance claims — a damaged car with undamaged areas digitally restored, a property photo with structural damage removed.

**SYNTHETIC** — An image that was entirely generated by an AI model. No real camera was involved anywhere in its creation. This is what you get from Midjourney, Stable Diffusion, DALL-E, and their equivalents.

These are forensically distinct problems. Most detection systems treat them as one. Veridify does not.

---

## How it works

Veridify runs two detection branches simultaneously and fuses their outputs into a single verdict.

**Spatial branch** — An EfficientNetB0 model pretrained on ImageNet and fine-tuned on our dataset. It learns the visual fingerprints that AI generators leave behind: texture patterns, edge inconsistencies, upsampling artifacts that are consistent across generator families.

**Frequency branch** — A mathematical analysis of the image at the pixel level. Real camera sensors capture light with natural random noise distributed across the frequency spectrum. AI generators produce images through learned upsampling operations that leave periodic artifacts — spikes at regular intervals in the DCT and FFT domain — that are invisible to the human eye but mathematically detectable. Tampered images show frequency discontinuities at manipulation boundaries. This branch catches what the spatial CNN cannot see.

Both branches feed into a classification head that produces a three-class output. The final response includes a trust score from 0 to 100, the verdict, a confidence label, and separate spatial and frequency sub-scores so the result is interpretable, not just a number.

## Who it is for

**Insurance companies** — Verify claim photos before approving payouts. Motor insurance, property insurance, health insurance. Any claim that arrives with photographic evidence.

**Online marketplaces** — Flag AI-generated product listings before they go live. Protect buyer trust. Reduce manual moderation load.

**Fact-checkers and newsrooms** — Verify whether a news image is authentic before publishing or amplifying it.

**Legal and court proceedings** — Authenticate photographic evidence submitted in civil cases.

**Any developer** who needs to add image authenticity checks to their own product via a single API call.

---

## The billing model

Each client gets a Squad Virtual Account funded in Naira. Every API call deducts ₦175 from that balance automatically. Clients top up via Squad Payment Link — card, bank transfer, or USSD. High-volume clients move to a monthly subscription.

The billing and the AI are one operation. The balance check runs before inference. If the balance is insufficient, the model never runs and a top-up link is returned instead. There is no way to get a verification without payment clearing first.

## Running it

### Prerequisites

- Python 3.11+
- Node.js 18+
- PostgreSQL
- Squad sandbox account — https://sandbox-dashboard.squadco.com

### Backend

```bash
cd backend
python -m venv venv
source venv/bin/activate
pip install -r requirements.txt

cp .env.example .env
# Fill in your values

alembic upgrade head
uvicorn app.main:app --reload --port 8000
```

API at `http://localhost:8000`. Docs at `http://localhost:8000/docs`.

### Frontend

```bash
cd frontend
npm install

cp .env.local.example .env.local
# Fill in your values

npm run dev
```

Dashboard at `http://localhost:3000`.

## API

All authenticated endpoints require `X-API-Key`.

### Create account

```
POST /account/create

{
  "name": "Sterling Assurance",
  "email": "claims@sterling.ng"
}
```

Returns an API key, Squad Virtual Account details, and a payment link to fund the account.

### Verify an image

```
POST /verify
X-API-Key: vrf_sk_live_...
Content-Type: multipart/form-data

file: <image>
```

```json
{
  "verification_id": "vrf_abc123",
  "trust_score": 82,
  "verdict": "AUTHENTIC",
  "confidence": "HIGH",
  "breakdown": {
    "spatial_score": 85,
    "frequency_score": 79
  },
  "processing_ms": 1240,
  "cached": false,
  "billed_naira": 175,
  "balance_remaining": 4825
}
```

`trust_score` is 0–100. Higher means more likely authentic. `cached: true` means the same image was submitted before — no charge on repeat submissions. A `402` response includes a Squad top-up link when balance is insufficient.

### Fund account

```
POST /account/fund
X-API-Key: vrf_sk_live_...

{ "amount_naira": 5000 }
```

Returns a Squad Payment Link. Balance is credited automatically when payment clears via webhook.

### Squad webhook

```
POST /webhook/squad
```

Receives `charge_successful` events from Squad. HMAC-SHA512 verified, idempotency-checked, then credits the matching client account.

## Honesty about limitations

The training data is not Nigeria-specific. CASIA v2, tampCOCO, and tiny-GenImage are internationally sourced datasets. Images heavily compressed by WhatsApp, or taken in lighting conditions underrepresented in the training set, may receive lower confidence scores. When the model is uncertain, it says so — `LOW — recommend human review` is a real output, not a fallback.

OOD accuracy drops on generator families not seen during training. We track this gap and report it honestly rather than hiding it behind aggregate numbers.
